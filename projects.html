Bad Decisions Analytics

I built this for CSE 135 as a way to see what was happening on a test store. The store sends information to a collector, which saves it in a database so the reporting site can use it.

What I built

The reports show things like website errors, loading times, and where people stop during checkout. I also added a place for analyst comments and a way to download the reports as PDFs.

How it works

  • I used PHP sessions and server-side permission checks to control who can see each report.
  • Database queries use prepared statements, and text is escaped before it appears on a page.
  • Most of the interface uses plain JavaScript and CSS.
  • GitHub Actions deploys changes to my DigitalOcean server.

Built with: PHP, MySQL, JavaScript, HTML, CSS, Apache, and Linux.

UCSD Gym Planner

What it does

The idea behind this project is to bring gym occupancy and planning into one place. It shows how crowded the UCSD gyms are and also has options for workouts, meals, and a weekly schedule.

Tools and limits

The project uses Python, Next.js, and JavaScript. One thing to keep in mind is that the forecasts depend on how much data is available. If there isn't enough matching data, the dashboard says that rather than giving an estimate it can't support.

Meme Generator

What it does

My team built a meme editor where someone can upload an image or choose a template, add their own text, and download the finished meme. The main idea was to keep those steps easy to use.

Tools

We used HTML, CSS, and JavaScript and hosted the app on GitHub Pages. There is also an optional AI mode for meme suggestions.
