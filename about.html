About me

Background

I'm studying Computer Engineering at UC San Diego. I like working on projects where I can see how the pieces connect, from what someone sees on the page to the code and data behind it.

I want the things I build to be useful. When I'm working on something, I try to ask, what would make this easier for someone to use?

Technical experience

Some of the tools I've used in these projects:

Web development

  • HTML, CSS, and JavaScript for web pages and interfaces.
  • Next.js for the gym planning dashboard.

Backend and data

  • PHP and MySQL for collecting website data and building reports.
  • Python for data collection.
  • GitHub Actions, Linux, Apache, and DigitalOcean for the CSE 135 project.

Leadership

Outside of class, I'm president of the Chancellor's Scholars Alliance. I work with the board to plan events, coordinate volunteer activities, and support peer mentoring.

A lot of that work comes down to communicating plans and making sure everyone knows what needs to get done.

How I approach projects

  1. Figure out what the project needs to do.
  2. Work through how the parts connect.
  3. Test it, fix problems, and explain what I'd change next.
